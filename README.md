# Noche de TAYA'xs

Carreras de midgets en el óvalo de tierra de Bahía Blanca, de noche y con las tribunas llenas. Versión para PC.

**Jugar:** https://pablog2081.github.io/noche-de-tayaxs/

- 140 pilotos por noche: series, repechajes, semis, prefinal y la Gran Final de 12.
- Autos sin caja: se doblan derrapando y el acelerador es el volante.
- Teclado (teclas configurables), joystick (Xbox / PlayStation) y volante de PC con calibración.
- Boxes comunitarios en las curvas 3 y 4, garage para gomas y service, relato de Fefón.

Controles por defecto: ↑/W acelerar · ←/A adentro · →/D contravolante · C cámara · V volante automático/manual · Esc pausa.
Joystick: gatillo derecho acelera, palanca izquierda dobla, Y cámara, X volante, Start pausa.
